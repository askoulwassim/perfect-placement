# @perfect-placement/mcp

**Owner: lane C.** One tool per op from `OPS` (`packages/contracts`), JSON Schema via `opInputJsonSchema`. Resources: profile card, role, company, contacts for a role, Needs-you queue. Transports: stdio and Streamable HTTP (served by `pp up`). High-impact / `humanOnly` ops return `requires_human` with the queued decision id.
